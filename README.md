Tienda Virtual de Ropa — Examen T1
Curso

Desarrollo de Aplicaciones Web I
Código del curso: PROG04694
Institución: Cibertec

Descripción del Proyecto

Este proyecto consiste en el desarrollo de una Tienda Virtual de Ropa, aplicando los conocimientos aprendidos durante las unidades del curso de Desarrollo de Aplicaciones Web I.

La aplicación implementa persistencia de datos utilizando Java Persistence API (JPA) y el framework Spring Data JPA, trabajando con entidades, relaciones entre tablas, herencia, consultas JPQL y optimización mediante estrategias de carga de datos.

Tecnologías utilizadas
Java JDK 17
Spring Boot 2.7.18
Spring Framework
Spring Data JPA
Hibernate 5.6
MySQL
Maven
IntelliJ IDEA
